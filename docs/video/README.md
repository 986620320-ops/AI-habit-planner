# 演示视频目录

本目录已包含：

- `demo-video-script.md`：6 分 30 秒分镜、旁白和录制检查表
- `subtitles.srt`：可直接导入剪辑软件的中文字幕

实际录制完成后，将文件命名为：

```text
AI习惯教练_演示视频_1080p.mp4
```

并放在本目录，或上传到 GitHub Release / 网盘后把链接写入：

```text
docs/SUBMISSION_INDEX.md
```

## 硬性要求

- 5～8 分钟
- 1920×1080
- MP4 / H.264
- AI 协同复现不少于 2 分钟
- 文件低于 GitHub 100MB 限制时可直接提交
- 超过 100MB 使用外部链接，不要强制加入 Git 历史
- 视频、截图和字幕均不得泄漏 API Key 或个人隐私
