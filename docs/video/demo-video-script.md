# 演示视频拍摄脚本（6 分 30 秒）

## 成片规格

- 分辨率：1920 × 1080
- 帧率：30 fps
- 格式：MP4 / H.264
- 时长：6 分 20 秒 - 6 分 50 秒
- 音频：普通话，48 kHz
- 字幕：使用同目录 `subtitles.srt`
- 文件大小：控制在 100 MB 以内
- 全程不得出现真实 API Key、`.env` 内容、账号信息和 Authorization 请求头

## 录制前准备

1. 浏览器准备两个窗口：
   - 线上应用 `https://ai-habit-demo.netlify.app/?v=3#checkin`
   - GitHub 仓库与一次真实 commit diff
2. Codex 打开本项目的真实对话历史，定位到“删除习惯积分漏洞”或“多模态证据改造”的 Prompt 与修复过程。
3. 终端运行并通过：
   - `node --check netlify/functions/api.js`
   - 浏览器或 API 回归测试
4. 页面使用 Mock 模式完成一次预演，避免现场额度不足。
5. 准备一张不涉及隐私的测试照片；没有照片时使用文字证据演示。
6. 使用 OBS Studio 或 Windows `Win + G` 录制全屏。
7. 录制前关闭通知、聊天软件和包含密钥的终端标签。
8. 在关键操作上放慢鼠标，字幕与操作保持同步。

## 分镜与旁白

### 00:00 - 00:40 问题与目标

**画面**

- 封面标题：AI 习惯教练
- 快速闪过三个痛点：计划难坚持、反馈不连续、验证方式不自然

**旁白**

“很多习惯工具能生成一份漂亮计划，却无法持续理解用户。传统打卡又常常只记录一个按钮，或者要求用户手写随机字符。我们想解决的是：让 AI 理解真实生活，并持续陪用户执行。”

### 00:40 - 02:00 核心产品闭环

**画面**

- 打开 #checkin
- 点击快捷问题“我最近总熬夜”
- 展示 AI 对话和三个习惯候选卡片
- 点击“全部导入”
- 展示证据按钮、积分与商城

**旁白**

“用户不需要一次填完整套问卷，可以直接描述当前困扰。AI 结合已有习惯和积分继续对话，并给出可以立即导入的候选习惯。完成导入后，用户通过照片、文字或语音留下真实证据，积分和奖励形成完整闭环。”

### 02:00 - 04:40 AI 协同过程复现（重点，不少于 2 分 40 秒）

**画面**

- Codex 对话窗口
- 展示用户原始 Prompt：
  “我发现两个问题：一，删除习惯后积分总额和流水还在，重新添加同名习惯后还能再次打卡得分。二，前端没有限制习惯数量，服务端最多处理 20 个。”
- 展示 AI 分析：复现路径、根因、扣回流水、habitId、20 个上限
- 展示实际修改文件 diff
- 打开终端运行检查
- 展示浏览器操作和积分前后变化
- 打开 Git commit `935550b`

**旁白**

“这一段展示真实的 AI 协同过程，不做后期伪造。我们先给出可复现的 Bug 描述，而不是只说页面错了。Codex 分析出三个关键点：历史流水需要绑定 habitId；删除习惯时按贡献扣回积分；前端必须和服务端一样限制二十个习惯。”

“随后 AI 实际修改代码，并运行语法检查和浏览器回归。第一次测试关注的是错误路径，发现积分发放函数在重构时缺失，控制台报 is not defined。我们把错误反馈给 Codex，让它继续定位、补回函数并重新执行完整流程。”

“验证通过后，改动被拆成独立 commit。评委可以从真实提交历史看到问题如何被发现、如何修复，而不是一次性生成全部代码。”
