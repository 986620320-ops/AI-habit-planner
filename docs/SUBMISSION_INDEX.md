## 评分维度对照

### 过程可复现性与演进链路

- 完整保留从空白骨架到当前版本的细粒度 Git 提交
- 5 条核心 AI 迭代均包含 Prompt、修改、Bug 修复、验证和对应提交
- 其中 3 条环节另有文字导出页、源日志行号和 SHA256；截图单独提交
- README 提供复现性声明、完整环境变量表、Mock 与真实 AI 两条复现路径
- `package-lock.json` 固定依赖，`npm run reproduce` 一键构建并执行回归
- GitHub Actions 在 Node.js 20.18.0 上自动验证安装、构建和测试

### 解题有效性与实用价值

- 连续对话、证据打卡、下一步反馈、断签恢复、每周复盘和积分兑换形成完整闭环
- 不要求手写随机字符，不强制固定拍摄物品
- 同时支持比赛演示和低成本日常使用

### 方法创新性与意图控制

- AI 结合当前习惯、积分和最近对话持续回答
- 周复盘只发送聚合数据，并限制每天 2 次真实调用
- 多模态自由证据、一次追问和手动复盘降级
- 结构化 JSON、上下文长度、输入限制和每日额度

### 工程质量与架构设计

- 单文件前端便于复现，Netlify Function 统一管理模型调用
- API Key 仅存在服务端环境变量
- API、浏览器、响应式、备份恢复和错误路径均有回归测试

### 用户体验与产品精细度

- 思考状态、逐字显示、失败重试和额度提示
- 手机与桌面响应式布局
- 断签恢复和每周复盘均提供空状态、失败提示和额度提示
- 候选习惯卡片和即时积分反馈
