## Prompt 链格式

每份文档包含：

- 用户原始 Prompt 或 Prompt 链
- AI 修改建议与取舍
- 实际实现内容
- 发现 Bug、复现和修复过程
- 测试与验收结果
- 对应 Git 提交
- 截图或录屏证据位置

## 证据要求

真实 Codex 对话截图放在 `evidence/`：

```text
01-codex.png
02-codex.png
03-codex.png
04-codex.png
05-codex.png
```

截图应至少包含：

- 用户原始提问
- AI 的方案或修改摘要
- Bug 复现/修复对话
- 最终测试或成功结果

截图和录屏不得包含：

- `.env` 内容
- API Key
- 浏览器 Authorization 请求头
- 个人账号或隐私信息

如 Codex 支持对话导出，优先同时保存原始导出文件；否则按照 `evidence/CAPTURE_GUIDE.md` 截图或录屏。
